# LZ4 / Zstd FPGA 优化实测（2026-11-01）

在同一张 KU5P 上比较原固件与本轮优化固件。GB/s 为十进制，每项为三轮中位数。
主机 SDK、基准二进制、输入数据、并发数与计时口径保持一致。
CPU 列引用同日的[原始对照](algorithm-performance-20261101.md)，本轮没有重新运行 CPU 编码器。

## 64 MiB chunk，约 50% 可压缩数据

| 算法 | 原 FPGA SDK GB/s | 新 FPGA SDK GB/s | 提升 | 新 FPGA 编码通道 GB/s | CPU 8 路 GB/s |
| --- | ---: | ---: | ---: | ---: | ---: |
| lz4 | 0.279 | 3.714 | 13.30× | 4.045 | 17.096 |
| zstd | 0.160 | 0.605 | 3.78× | 0.609 | 13.140 |

SDK 使用实际接口，LZ4/Zstd 的完整解码及 CRC 校验计入时间。编码通道把完整输出
校验放到计时后；每一份输出仍需解压并逐字节一致，才发布速度。这里测压缩组件，
不代表 compactfs 的 fio 前台写入速度。gzip/raw 继续使用原验收镜像，本轮未改动。

## 实现变化

- LZ4 保持四个 DMA 引擎、250 MHz；每引擎分配 8 条 LZ77 通道。读入、编码和
  顺序写出并行执行，尝试编码与保留原文均以 64 位队列传输，原文保留使用 URAM。
- LZ4 块由 32 KiB 改为 8 KiB，字典候选由 2 个改为 1 个，扩展窗口由 32 KiB
  改为 4 KiB；因此收益也包含编码参数的变化，压缩比需结合上表判断。标准帧格式不变。
- Zstd 保持两个 DMA 引擎、125 MHz、8 KiB 块；每引擎 LZ77 通道由 1 条增为
  4 条，共享树生成和 FSE 阶段。频率队列按全部通道的完整表及结束标志分配，
  修复四通道汇合时的背压死锁；继续保留字典和频率 RAM 的真实依赖。

两种算法仍有流水线和资源限制，不能把 gzip 的既有吞吐直接套用到其他格式。

## 验证与复现

每种最终候选均通过 115 组 C 仿真、25 组 RTL 回归、3 组与板测同种子的随机
RTL 回归（含 1 MiB），由纯 Go 解码并逐字节比较。RTL/ROM 文件在两套回归中逐文件
SHA256 相同，另用原生 LZ4/Zstd 解码器复核三份 DMA 输出。
完整镜像通过 setup、hold、时钟覆盖和 DRC 检查后才经易失 JTAG 装载。

上板逐核验证 72 组普通输入、18 组边界输入，再经压缩服务验证 12 组输入。
性能部分共 90 组、24.75 GiB 输入，全部完整解压比对。
4 MiB 稳定性补测另外 9 组、36.00 GiB，也全部解压比对通过。
compactfs 在同一挂载与 worker 下切换 gzip、新 LZ4、新 Zstd，共写入 192 MiB，
确认实际 FPGA 编码且 CPU 回退增量为零；随后关闭 SSD 缓存和内存读缓存重挂载，
从 backend 解码全部文件，SHA256 一致。

基准固定 Go 1.26、CGO=0、P=8；128 MiB/路、4/64 MiB chunk、三轮。
CPU 亲和 `8-23,56-71`，XDMA IRQ `0-23,48-71`，均为 NUMA0。
完整镜像构建使用 NUMA1；测试输入和输出位于 RAM，日志写 `/data1`，
不把磁盘读写、数据生成或预分配计入速度。
fixture 解码后 SHA256 为
`d378f587d40daec3d80194bf95ba89d3b8851097cd5adc538ebff7955f5b77a1`。

基准命令沿用原报告的 `examples/benchmark-algorithms`。完整命令、三轮原始结果、
源文件、HLS IP、时序报告与混合读取记录位于 `/data1/fpga-algorithm-opt-20261101-xnr5z9nf`。
最终归档为 `/root/FPGA-4IP/qz01_compress_4ip/validated/20261101-algorithm-opt`，
包含各算法的源码、IP、bitstream、manifest、参考工程与验收记录。在该目录运行
`./switch.sh lz4` 或 `./switch.sh zstd` 即可通过 JTAG 切换；`./switch.sh gzip` 恢复 gzip。
[机器可读结果](algorithm-optimization-20261101.json)保留中位数、范围、压缩比和原始报告哈希。
